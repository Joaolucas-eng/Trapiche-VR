# Trapiche VR

Simulação em Realidade Virtual focada na reconstrução histórica e imersão no Complexo Trapiche Santo Ângelo. Este projeto acadêmico tem como objetivo preservar e apresentar a história do local através de uma experiência interativa.

## 🚀 Tecnologias
* **Motor Gráfico:** Unity 3D
* **Linguagem de Programação:** C#
* **Plataforma:** Realidade Virtual (VR)

## ⚙️ Funcionalidades
* Navegação imersiva em primeira pessoa pelo cenário histórico.
* Gatilhos de informação interativos (`InfoTrigger.cs`) para exibição de detalhes e curiosidades do trapiche.
* Interação com o ambiente e exploração da modelagem 3D.
